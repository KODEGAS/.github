# Kodegas

**Kodegas** is a forward-thinking tech studio specializing in weaving AI, Machine Learning, IoT, Web, and Mobile applications into tools that make an impact. We're not about empty hype—we build with clarity, science, and a human touch.

---

## What We Do

We don't just talk cutting edge—we live it. Kodegas crafts applications that:

- Detect and diagnose crop diseases using AI (like our sub-project **WeGuard**).
- Use IoT sensors to feed real-time farming or environmental data.
- Deliver polished web and mobile experiences with sleek animations (yes, maybe Three.js, smooth transitions—that Apple-level polish).
- Fuse data, design, and user empathy to solve genuine problems.

---

## Our Philosophical North Star

Technology needs to be curious, not obscure. We lean into the weirdness of the world. Our philosophy:

- Build tools that think, but don’t alienate.
- Let data inform, but creativity ignite.
- Use AI and IoT as bridges, not black boxes.
- Favor open systems, not locked gates.
